# 2026-11-07 工作日志

## Xcode 编译错误修复
- 现象：用户在 Xcode 编译报错误（命令行 `swift build` 正常通过）。
- 根因：`AiguruBoot.xcodeproj` 工程文件过时（最后生成于 2026-10-25），未纳入 11-06 新增的两个源文件 `Sources/AiguruBootCore/AgentCredentialStore.swift` 与 `AgentCredentialsView.swift`。这两个文件被 `LlmRootView.swift` 引用/定义，Xcode 因工程里没有编译它们而报“找不到类型/符号”类编译错误。`swift build` 走 `Package.swift`（目录级 target），与过时的 xcodeproj 无关，因此一直能过。
- 修复：运行 `xcodegen generate --spec project.yml` 重新生成 `xcodeproj`（XcodeGen 使用目录级引用 `Sources/AiguruBootCore`，自动包含全部 .swift）。生成后 pbxproj 中 `AgentCredential` 引用从 0 → 8 处，AiguruBootCore 的 swift 文件 18 → 20。
- 验证：`xcodebuild build -scheme AiguruBoot -configuration Debug -destination 'generic/platform=macOS'` → **BUILD SUCCEEDED**。
- 约定（重要）：本项目 Xcode 工程由 XcodeGen 管理（`project.yml`）。**每次新增/移动/删除源文件后，必须重新运行 `xcodegen generate`** 重新生成 `xcodeproj`，否则 Xcode 编译会与实际源码布局脱节。
- 用户侧操作：若 Xcode 已打开该工程，需重新打开 `AiguruBoot.xcodeproj` 以重新加载 pbxproj。
